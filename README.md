# 청년정책 신청 도우미

이미 찾은 청년정책을 왜 신청하지 못하는지 진단하고, 신청 준비, 정책 개선 제안, 공식 기관 문의 중 알맞은 다음 행동으로 연결하는 인터랙티브 MVP입니다.

> 판정 기준은 공식 안내에서 가져왔고, 사용자는 본인 정보만 입력합니다. 다만 입력값만 비교한 **모의 판정**이며, 실제 자격은 공식 기관이 공적자료를 조회해 심사로 결정합니다.

## 실행 방법

Node.js LTS(20.9.0 이상)가 필요합니다.

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # 판정 엔진과 정책 데이터 테스트
npm run lint
npm run typecheck
npm run build
```

## 다루는 정책

| 정책 | 판정 범위 | 신청 기간 | 기준 출처 |
|---|---|---|---|
| 청년월세 지원 | 연령, 무주택, 별도 거주, 전입신고, 제외 대상, 청년가구·원가구 소득과 재산 | 2026.03.30 ~ 05.29 (마감) | 복지로 공지 (2026.03.20) |
| 국민취업지원제도 I유형 (청년) | 연령(병역 가산), 가구 소득·재산, 본인 소득, 근로 상태, 참여 제한 | 상시 | 고용24 안내 (2025.12.30) |

- 청년월세는 접수가 끝나 신청 버튼 대신 "2026년 접수 마감"과 다음 공고 대비 안내를 보여줍니다.
- 국민취업지원제도는 I유형만 판정하고, 미충족이면 II유형을 안내만 합니다.
- 기준 중위소득은 2026년 보건복지부 고시 값입니다. 연도가 바뀌면 `src/data/medianIncome.ts`와 공고를 함께 갱신해야 합니다.

## 확인 중인 기준

공고 원문으로 확인하지 못한 기준은 규칙에 `verified: false`를 두고 화면에 "확인 중인 기준"으로 표시합니다. 이 기준에 맞지 않아도 미충족으로 확정하지 않고 "추가 확인 필요"로 판정합니다.

| 정책 | 기준 | 현재 근거 |
|---|---|---|
| 청년월세 | 청년가구 재산 1억 2,200만 원, 원가구 재산 4억 7,000만 원 | 정부24 인천시 사업 안내 |
| 청년월세 | 전입신고, 공공임대·가족 주택·중복 지원 제외, 제출서류 | 정부24 인천시 사업 안내 |
| 국민취업지원제도 | 본인 월소득 153만 8,543원 이하 | 고용24 안내 (청년특례 적용 여부 불명확) |

전국 공고 원문으로 확인하면 `src/data/policies/` 의 해당 규칙을 `verified: true`로 바꾸고 출처를 교체합니다.

## 판정 규칙

- **조건 판정:** `MET`(충족), `NOT_MET`(미충족), `UNKNOWN`(미입력 또는 모르겠어요), `NOT_APPLICABLE`(해당 없음)
- **판정 결과 구조:** 조건마다 `ruleId`, `status`, `reason`, `evidence`(입력값, 비교 기준, 참고 자료), `source`를 돌려줍니다.
- **진행률:** 해당하는 조건과 서류를 합산합니다. 해당 없는 조건(예: 만 30세 이상의 부모님 소득)은 분모에서 빠집니다.
- **최종 경로:** 확인된 기준 미충족 → 확인 필요(미입력, 모르겠어요, 확인 중인 기준 미충족, 기관 확인 대기) → 서류 부족 → 신청 준비 완료 순서입니다.
- **신청 버튼:** 준비 완료, 진행률 100%, 접수 기간 중일 때만 열립니다.

## 주요 파일

| 파일 | 역할 |
|---|---|
| `src/lib/rules/` | 순수 판정 엔진 (규칙 평가, 적용 조건, 답별 판정 미리보기 `previewOutcomes`, 접수 기간). 외부 API와 AI를 import하지 않으며 테스트가 이를 검사합니다 |
| `src/data/policies/` | 정책별 질문, 규칙, 서류, 출처, 접수 기간. 규칙마다 사람이 검수한 `plainText`와 `howToCheck`를 둡니다 |
| `src/data/medianIncome.ts` | 연도별 기준 중위소득 |
| `src/lib/diagnosis.ts` | 규칙 판정, 진행률, 최종 경로, 질문 화면 구성 |
| `src/lib/drafts.ts` | 정책 개선 제안문, 기관 문의문 템플릿 |
| `src/components/PolicyHelper.tsx` | 화면 상태와 단계 흐름 |
