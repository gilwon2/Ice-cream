# 청년정책 신청 도우미

이미 찾은 청년정책을 왜 신청하지 못하는지 진단하고, 신청 준비, 정책 개선 제안, 공식 기관 문의 중 알맞은 다음 행동으로 연결하는 인터랙티브 MVP입니다.

> 판정 기준은 공식 안내에서 가져왔고, 사용자는 본인 정보만 입력합니다. 다만 입력값만 비교한 **모의 판정**이며, 실제 자격은 공식 기관이 공적자료를 조회해 심사로 결정합니다.

## 실행 방법

Node.js LTS(20.9.0 이상)가 필요합니다.

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # 판정 엔진과 정책 데이터 테스트
npm run lint
npm run typecheck
npm run build
```

## 다루는 정책

| 정책 | 판정 범위 | 신청 기간 | 기준 출처 |
|---|---|---|---|
| 청년월세 지원 | 연령, 무주택, 별도 거주, 전입신고, 제외 대상, 청년가구·원가구 소득과 재산 | 2026.03.30 ~ 05.29 (마감) | 복지로 공지 (2026.03.20) |
| 국민취업지원제도 I유형 (청년) | 연령(병역 가산), 가구 소득·재산, 본인 소득, 근로 상태, 참여 제한 | 상시 | 고용24 안내 (2025.12.30) |

- 청년월세는 접수가 끝나 신청 버튼 대신 "2026년 접수 마감"과 다음 공고 대비 안내를 보여줍니다.
- 국민취업지원제도는 I유형만 판정하고, 미충족이면 II유형을 안내만 합니다.
- 기준 중위소득은 2026년 보건복지부 고시 값입니다. 연도가 바뀌면 `src/data/medianIncome.ts`와 공고를 함께 갱신해야 합니다.

## 사용 흐름

화면은 3단계입니다. 다음 행동은 사용자가 고른 이유가 아니라 **판정 결과로** 정합니다.

1. **정책 선택:** 신청하려던 정책을 고릅니다.
2. **상황 확인:** 질문에 답하고(모르면 "모르겠어요" 또는 빈칸), 제출서류를 체크하고, 원하면 상황 메모를 남깁니다. 메모는 브라우저에서 문의문·건의문에만 끼워 넣고 서버·AI로 보내지 않습니다.
3. **해결 안내:** 결과 요약(충족·미충족·확인 필요 개수) → 막힌 조건(4개 이상이면 3개만 먼저, 충족 조건은 접힘) → 다음 행동 선택 순서입니다.

| 판정 결과 | 추천 행동(먼저 열림) | 함께 고를 수 있는 행동 |
|---|---|---|
| 확인 필요(미입력, 모르겠어요, 확인 중인 기준 미충족) | 기관에 문의하기 (AI 문의문 + 전화) | 신청 준비 |
| 서류 부족 / 신청 준비 완료 | 신청 준비 (서류 체크리스트 + 공식 신청 사이트) | 기관에 문의하기 |
| 확인된 기준 미충족 | 기준 다시 확인하기 (확인 방법 + AI 문의문 + 전화) | 정책 개선 건의하기 |

미충족이면 당장 받을 수 있는 도움을 먼저 보여줍니다: 막힌 조건 → 기준을 다시 확인할 방법 → 다른 지원 경로(대안 안내 + 비슷한 청년정책) → 맨 아래 "원하면 정책 개선을 건의할 수 있어요"(AI 건의문 + 청년신문고). 단계 표시에서 해결 안내는 상황 확인을 끝까지 거쳐야 열리고, 정책을 바꾸면 다시 잠깁니다.

## 확인 중인 기준

공고 원문으로 확인하지 못한 기준은 규칙에 `verified: false`를 두고 화면에 "확인 중인 기준"으로 표시합니다. 이 기준에 맞지 않아도 미충족으로 확정하지 않고 "추가 확인 필요"로 판정합니다.

| 정책 | 기준 | 현재 근거 |
|---|---|---|
| 청년월세 | 청년가구 재산 1억 2,200만 원, 원가구 재산 4억 7,000만 원 | 정부24 인천시 사업 안내 |
| 청년월세 | 전입신고, 공공임대·가족 주택·중복 지원 제외, 제출서류 | 정부24 인천시 사업 안내 |
| 국민취업지원제도 | 본인 월소득 153만 8,543원 이하 | 고용24 안내 (청년특례 적용 여부 불명확) |

전국 공고 원문으로 확인하면 `src/data/policies/` 의 해당 규칙을 `verified: true`로 바꾸고 출처를 교체합니다.

## 판정 규칙

- **조건 판정:** `MET`(충족), `NOT_MET`(미충족), `UNKNOWN`(미입력 또는 모르겠어요), `NOT_APPLICABLE`(해당 없음)
- **판정 결과 구조:** 조건마다 `ruleId`, `status`, `reason`, `evidence`(입력값, 비교 기준, 참고 자료), `source`를 돌려줍니다.
- **진행률:** 해당하는 조건과 서류를 합산합니다. 해당 없는 조건(예: 만 30세 이상의 부모님 소득)은 분모에서 빠집니다.
- **최종 경로:** 확인된 기준 미충족 → 확인 필요(미입력, 모르겠어요, 확인 중인 기준 미충족) → 서류 부족 → 신청 준비 완료 순서입니다.
- **공식 신청 사이트 버튼:** 모의 판정 결과와 관계없이 항상 열리며, 실제 자격과 신청은 공식 사이트(복지로, 고용24)에서 확인하도록 새 창으로 엽니다.

## 배포 및 환경변수

Next.js 앱이라 Node.js 20.9.0 이상을 지원하는 곳이면 어디서나 실행할 수 있습니다. 배포 설정 파일은 Vercel용 `vercel.json` 하나입니다.

- **실행 지역:** `vercel.json`의 `"regions": ["icn1"]`로 서버 함수를 서울에서 실행합니다. Vercel 기본 지역(미국 `iad1`)에서는 온통청년 API가 해외 요청을 막거나 느릴 수 있기 때문입니다. Next.js 16의 `preferredRegion` 설정은 지원이 중단되어(deprecated) 쓰지 않습니다. Hobby 요금제는 지역을 1개만 고를 수 있습니다.

```bash
npm ci
npm run build
npm start          # 기본 포트 3000, -p 로 변경
```

Vercel 같은 호스팅을 쓰면 저장소를 연결한 뒤 아래 환경변수를 프로젝트 설정에 넣습니다. 로컬에서는 `.env.example`을 `.env.local`로 복사해 값을 채웁니다.

| 변수 | 필수 | 기본값 | 설명 |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | 아니요 | 없음 | Claude API 키. 비워 두면 AI 기능 없이 판정과 고정 템플릿 안내만 동작합니다 |
| `ANTHROPIC_MODEL` | 아니요 | `claude-sonnet-5-5` | 사용할 모델 |
| `DEMO_ACCESS_CODE` | AI를 쓰려면 예 | 없음 | AI 기능 시연용 접근 코드. 비워 두면 AI 라우트가 503으로 닫힙니다 |
| `AI_RATE_LIMIT_PER_MINUTE` | 아니요 | `30` | IP당 1분 AI 요청 수. 1 이상의 정수만 받고, 잘못된 값이면 30으로 돌아갑니다 |
| `YOUTH_POLICY_API_KEY` | 아니요 | 없음 | 온통청년 청년정책 Open API 인증키. 결과 화면의 "비슷한 청년정책" 추천에만 씁니다. 비워 두거나 호출이 실패하면 미리 정리한 대체 목록을 보여줍니다 |

- 모든 변수는 서버에서만 읽습니다(`src/lib/ai/config.ts`, `src/lib/policyApi/youthPolicy.ts`, `server-only`). `NEXT_PUBLIC_` 접두사를 붙이면 브라우저로 노출되므로 붙이지 않습니다.
- `.env*` 파일은 커밋하지 않습니다. `.env.example`만 값을 비운 채로 저장소에 둡니다.
- 호출 제한은 서버 프로세스 메모리에서 세므로 서버 인스턴스마다 따로 셉니다. 같은 네트워크(같은 IP)의 여러 사용자는 합쳐서 세므로, 심사처럼 동시 접속이 예상되면 값을 넉넉히 둡니다. 값을 바꾸면 서버를 다시 시작해야 합니다.
- AI 라우트(`/api/ai/session`, `/api/explain`, `/api/drafts`)는 호출 제한 → 접근 코드 → 본문 검증 순서로 요청을 막습니다. AI가 실패하거나 8초 안에 응답하지 않으면 고정 템플릿과 기본 안내로 대체합니다.
- 추천 라우트(`/api/policy-recommendations?policyId=…`)는 정책 ID만 받습니다. 온통청년 응답은 서버에서 정책 분야별로 1시간 캐시하고, 5초 안에 응답이 없거나 오류·0건이면 대체 목록을 보여줍니다. 로그에 남는 요청 주소의 `apiKeyNm` 값은 가립니다.

## 개인정보 처리

이 앱은 회원가입이나 서버 저장 없이 동작하며, 외부 AI에는 개인정보를 보내지 않도록 설계했습니다.

| 데이터 | 어디에 있나 | 외부 AI 전송 |
|---|---|---|
| 판정용 입력값(생년월일, 소득·재산 금액, 가구원 수, 병역 기간 등) | 브라우저 화면 상태(새로고침하면 사라짐). AI 설명을 요청할 때 판정을 다시 계산하도록 이 서버로 보내지만 저장하지 않습니다 | **보내지 않음** |
| 조건별 판정 상태, 정책 기준, 공고 출처 | 서버가 입력값으로 다시 계산 | 보냄(AI 설명·초안 작성에 필요) |
| 상황 메모(자유 입력) | 브라우저 화면 상태 | **보내지 않음.** 고정 템플릿에만 들어가고, AI 초안에는 `[상세 상황]` 자리표시자를 둡니다 |
| AI가 만든 설명·초안 | 브라우저 `sessionStorage`(탭을 닫으면 사라짐) | — |
| 접근 코드, AI 이용 동의 여부 | 브라우저 `sessionStorage` | 보내지 않음(서버에서 해시를 고정 시간에 비교) |
| 요청 IP | 서버 메모리의 호출 제한 카운터(1분 단위로 세고 파일·DB에 저장하지 않음, 서버를 다시 시작하면 사라짐) | 보내지 않음 |

- AI 요청 스키마는 `z.strictObject`로 정해 두어 이름, 연락처, 주소, 자유 메모 필드를 받지 않습니다. 사용자 입력값이 프롬프트에 들어가지 않는지 `src/lib/ai/privacy.test.ts`가 검사합니다.
- AI 기능을 처음 쓸 때 무엇이 전송되는지 안내하고 동의를 받습니다. 입력 화면에는 이름·연락처·주민등록번호를 넣지 말라는 안내를 둡니다.
- 문의문·제안문의 서명은 `[이름]`, `[연락처]` 자리표시자로 두며, 사용자가 복사해 직접 채운 뒤 공식 채널에 제출합니다. 앱이 기관에 자동으로 보내지 않습니다.
- 온통청년 청년정책 API에는 진단 중인 정책의 분야(대분류·중분류)만 보냅니다. 생년월일, 소득, 가구원 수, 거주지 같은 입력값은 보내지 않으며(`zipCd` 미사용), `src/lib/policyApi/youthPolicy.test.ts`가 이를 검사합니다.
- 판정은 입력값만 비교한 모의 판정입니다. 테스트·시연 데이터는 모두 가상 데이터입니다.
